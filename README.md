# VerseType 사용 방법

## 설치

[VerseType GitHub 저장소](https://github.com/sorrychoe/VerseType)의 Releases에 설치 파일이 게시되어 있으면 내려받습니다. 테스트 파일은 Actions의 **Build and distribute app** 실행 결과에서 **Artifacts → install-files**를 받아 압축을 풉니다. 아티팩트 다운로드에는 GitHub 로그인이 필요할 수 있습니다.

- **Android:** `.apk` 파일을 휴대폰에 내려받아 엽니다. 요청되면 사용한 브라우저나 파일 앱의 앱 설치 권한을 허용하고 설치합니다.
- **iPhone:** 현재 iOS 배포는 준비 중이며 설치 파일을 제공하지 않습니다.

## 이달 말씀 타이핑

1. 앱을 열면 이달 말씀 입력창과 키보드가 나타납니다.
2. 표시된 말씀 본문을 입력합니다. 성경 구절 주소와 문장부호는 입력하지 않아도 됩니다.
3. 틀린 글자는 빨간색과 밑줄로 표시됩니다. 한글을 조합 중인 마지막 글자는 판정을 잠시 기다립니다.
4. 원문 없이 연습하려면 **가리고 쓰기**를 켭니다.
5. 본문을 끝까지 맞게 입력하면 완료 횟수와 오늘 출석이 기록됩니다. **다시 쓰기**로 반복할 수 있습니다.

## 지난 말씀 연습

**지난달 말씀**을 누르면 이전 말씀을 보고 입력할 수 있습니다. 상단 월 버튼으로 원하는 달을 선택하세요. 회색 버튼은 말씀이 없는 달이며, 이달 버튼을 누르면 시작 화면으로 돌아갑니다.

1월에는 전년도 월 버튼도 표시됩니다. 월을 바꾸면 입력 내용은 초기화되고 **가리고 쓰기** 설정은 유지됩니다.

## 출석 확인

시작 화면의 **연속 n일 · 이번 달 n일**을 누르면 출석 달력이 열립니다. **이전 달**과 **다음 달**로 기록을 확인할 수 있습니다.

앱을 열거나 일부만 입력하면 출석되지 않습니다. 어떤 달의 말씀이든 한 편을 끝까지 맞게 입력해야 하며, 같은 날 여러 번 완료해도 출석은 하루로 기록됩니다. 오늘 아직 완료하지 않았어도 어제까지 이어진 연속 출석은 유지됩니다.

## 말씀과 기록

이달 말씀이 아직 없으면 안내와 함께 최근 말씀을 표시합니다. 매년 1월에 1년치 말씀이 포함된 새 앱이 배포됩니다. GitHub에서 새 설치 파일을 받아 기존 앱 위에 업데이트 설치하세요. 설치된 말씀은 오프라인에서도 사용할 수 있고, 월이 바뀌면 해당 월 말씀으로 자동 전환됩니다.

완료 횟수와 출석은 현재 기기에만 저장됩니다. 앱을 삭제하거나 앱 데이터를 지우면 기록이 사라지며, 다른 기기로 자동 동기화되지 않습니다.
