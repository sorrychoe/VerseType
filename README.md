# VerseType 사용 방법

## 열기 및 홈 화면에 추가

[하늘소리 암송말씀 열기](https://www.heavensvoicechurch.com/VerseType/)

- **Android Chrome:** 위 주소를 열고 브라우저 메뉴 → **홈 화면에 추가** 또는 **앱 설치**를 선택합니다.
- **iPhone Safari:** 위 주소를 열고 공유 메뉴 → **홈 화면에 추가**를 선택합니다.
- 홈 화면에 추가하지 않고 브라우저에서 바로 사용해도 됩니다. APK 다운로드나 Apple 계정·기기 등록은 필요 없습니다.

키보드가 나타나지 않으면 말씀 입력창을 한 번 누르세요.

## 오프라인과 업데이트

처음에는 인터넷에 연결한 상태로 열고 화면 아래 **오프라인 사용 준비 완료**가 표시될 때까지 기다립니다. 이후에는 오프라인으로 말씀 입력·월 선택·출석 확인이 가능합니다. 브라우저가 저장 공간을 비우거나 사이트 데이터를 삭제하면 다시 온라인으로 열어야 합니다.

**새 버전 준비 완료**가 표시되면 이 앱을 열어 둔 탭과 홈 화면 앱을 모두 닫고 다시 엽니다. 입력 도중 자동으로 새로고침하지 않습니다.

## 이달 말씀 타이핑

1. 앱을 열면 이달 말씀 화면이 나타납니다. iPhone에서 키보드가 열리지 않으면 입력창을 누릅니다.
2. 표시된 말씀 본문을 입력합니다. 성경 구절 주소와 문장부호는 입력하지 않아도 됩니다.
3. 틀린 글자는 빨간색과 밑줄로 표시됩니다. 한글을 조합 중인 마지막 글자는 판정을 잠시 기다립니다.
4. 원문 없이 연습하려면 **가리고 쓰기**를 켭니다.
5. 본문을 끝까지 맞게 입력하면 완료 횟수와 오늘 출석이 기록됩니다. **다시 쓰기**로 반복할 수 있습니다.

## 지난 말씀 연습

**지난달 말씀**을 누르면 이전 말씀을 보고 입력할 수 있습니다. 상단 월 버튼으로 원하는 달을 선택하세요. 회색 버튼은 말씀이 없는 달이며, 이달 버튼을 누르면 시작 화면으로 돌아갑니다.

1월에는 전년도 월 버튼도 표시됩니다. 월을 바꾸면 입력 내용은 초기화되고 **가리고 쓰기** 설정은 유지됩니다.

## 출석 확인

시작 화면의 **연속 n일 · 이번 달 n일**을 누르면 출석 달력이 열립니다. **이전 달**과 **다음 달**로 기록을 확인할 수 있습니다.

앱을 열거나 일부만 입력하면 출석되지 않습니다. 어떤 달의 말씀이든 한 편을 끝까지 맞게 입력해야 하며, 같은 날 여러 번 완료해도 출석은 하루로 기록됩니다. 오늘 아직 완료하지 않았어도 어제까지 이어진 연속 출석은 유지됩니다.

## 말씀과 기록

이달 말씀이 아직 없으면 안내와 함께 최근 말씀을 표시합니다. 매년 1월에 1년치 말씀이 포함된 새 앱이 배포됩니다. 온라인 접속 시 새 버전을 받고 앱과 탭을 모두 닫았다가 다시 열어 적용합니다. 월이 바뀌면 해당 월 말씀으로 자동 전환됩니다.

완료 횟수와 출석은 현재 브라우저 저장소에만 저장됩니다. 사이트 데이터를 지우면 기록이 사라집니다. 다른 기기·브라우저와 동기화되지 않으며, 이전 APK의 기록은 웹 앱으로 자동 이전되지 않습니다.
